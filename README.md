# 🎧 تحلیلگر هوشمند صوت و تلاوت قرآن

مجموعه‌ای از ابزارهای تحلیل صوتی، از تحلیل موسیقایی عمومی تا تحلیل تخصصی و
دقیق تلاوت قرآن با تشخیص مقام عربی، نمایش زنده روی پیانو، و مقایسه ملودیک
دو فراز.

## فهرست ابزارها

| ابزار | توضیح |
|---|---|
| `web/index.html` | اپ وب مستقل (بدون سرور) برای تحلیل موسیقی عمومی — آپلود/میکروفون، BPM، کلید |
| `python/audio_analyzer.py` | تحلیلگر موسیقی عمومی با `librosa` (BPM، کلید، MFCC، طیف) |
| `python/pitch_engine.py` | **هسته مشترک**: استخراج دقیق pitch با Praat + تبدیل نت + DTW |
| `python/quran_maqam_analyzer.py` | تحلیل دقیق تلاوت قرآن + تشخیص مقام عربی |
| `python/piano_visualizer.py` | نمایش زنده نت روی کلاویه پیانو (از فایل یا میکروفون) |
| `python/compare_recitations.py` | مقایسه ملودیک/ریتمیک دو فراز با DTW |

## نصب

```bash
cd python
pip install -r requirements.txt
```

برای نمایش صحیح فارسی در نمودارها، فونت Vazirmatn را در `~/.fonts/` قرار دهید:
```bash
mkdir -p ~/.fonts
curl -sL -o ~/.fonts/Vazirmatn-Regular.ttf \
  "https://github.com/rastikerdar/vazirmatn/raw/master/fonts/ttf/Vazirmatn-Regular.ttf"
```

برای `piano_visualizer.py` (پخش صدا/میکروفون)، کتابخانه سیستمی PortAudio هم لازم است:
```bash
sudo apt-get install -y portaudio19-dev libportaudio2
```

## ۱. `pitch_engine.py` — هسته مشترک

این ماژول پایه همه ابزارهای دقیق پروژه است و مستقیماً اجرا نمی‌شود، بلکه
توسط بقیه فایل‌ها ایمپورت می‌شود. شامل:

- **استخراج F0 با موتور Praat** (نه librosa) — در آزمایش داخلی ما، Praat
  روی تن خالص و تن ربع‌پرده‌ای خطای **~۰ سنت** داشت در مقابل **~۷ سنت خطای
  pYIN** (که برای ربع‌پرده‌های ۵۰ سنتی مقام‌های عربی ناکافی است).
- تبدیل فرکانس ↔ نت پیانو ↔ موقعیت فیزیکی کلید (برای رسم روی کلاویه).
- فیلتر میانه (median filter) برای حذف نویز گذرا در لحظات حمله/فرود صدا.
- ادغام هوشمند قطعات مجاورِ هم‌پرده به یک نت واحد.
- پیاده‌سازی کامل **DTW** (Dynamic Time Warping) برای مقایسه ملودیک.

## ۲. `quran_maqam_analyzer.py` — تحلیل دقیق تلاوت + تشخیص مقام

```bash
python3 quran_maqam_analyzer.py recitation.mp3
python3 quran_maqam_analyzer.py recitation.wav --denoise
python3 quran_maqam_analyzer.py recitation.mp3 --output report.json --top-k 3
```

**قابلیت‌ها:**
- پاس دوگانه Praat برای دقت بالاتر + پاک‌سازی خطای جهش اکتاوی
- تفکیک نت‌به‌نت با زمان‌بندی دقیق
- تشخیص ویبراتو (نرخ Hz و دامنه سنت)
- تشخیص مقام از بین ۱۰ مقام اصلی (رست، بیات، حجاز، صبا، نهاوند، عجم، کرد،
  چهارگاه، سیکاه، نکریز) — بر پایه **استاندارد کنگره قاهره ۱۹۳۲**
- تشخیص سکوت‌ها/نفس‌ها و دامنه ملودیک (Ambitus)
- رسم ملوگراف (نمودار دقیق F0 + خطوط راهنمای مقام تشخیصی)

**⚠️ محدودیت صادقانه:** تشخیص مقام یک برآورد آماری از روی توزیع نت‌هاست
(مثل الگوریتم کروم‌هنسل-اشموکلر در موسیقی غربی)، نه تحلیل کامل «سیر ملودیک».
برای تلاوت‌های طولانی با چند مقام، فایل را به بخش‌های کوچک‌تر تقسیم کنید.

## ۳. `piano_visualizer.py` — نمایش زنده نت روی پیانو 🎹

یک کلاویه ۸۸-کلیدی رسم می‌کند و هم‌زمان با پخش صدا (یا میکروفون)، نت فعلی
را روی کلاویه هایلایت می‌کند — شبیه "پیانوی شبح" در نرم‌افزارهای آموزشی.

```bash
# پخش فایل صوتی + نمایش هم‌زمان پیانو
python3 piano_visualizer.py --file recitation.mp3

# ورودی زنده میکروفون
python3 piano_visualizer.py --mic
```

**ویژگی رنگ‌بندی کلید:**
- 🟢 سبز: نت دقیقاً کوک است (کمتر از ۱۵ سنت انحراف)
- 🟠 نارنجی: انحراف متوسط (۱۵ تا ۳۵ سنت)
- 🔴 قرمز: انحراف زیاد یا **ربع‌پرده** (نزدیک ۵۰ سنت) — این دقیقاً حالتی
  است که برای نت‌های خاص مقام‌های عربی (مثل سیکاه) طبیعی و مورد انتظار است.

> نیازمند محیط دسکتاپ با GUI و دستگاه صوتی (میکروفون/بلندگو) است. در محیط
> سرور بدون صفحه‌نمایش (headless) اجرا نمی‌شود.

## ۴. `compare_recitations.py` — مقایسه دقیق دو فراز 🔍

```bash
python3 compare_recitations.py reference.mp3 performance.mp3
python3 compare_recitations.py reference.mp3 performance.mp3 --output compare.json
```

فراز مرجع (مثلاً تلاوت یک قاری معروف) را با فراز دیگری (اجرای کاربر) از
سه بعد مقایسه می‌کند:

1. **شباهت ملودیک** (وزن ۵۵٪) — با DTW روی دنباله نت‌ها، به‌صورت *نسبی*
   (نرمال‌شده با میانه پرده صدای خودش) تا مستقل از زیر-و-بمی مطلق دو گوینده باشد.
2. **شباهت ریتمیک** (وزن ۳۰٪) — الگوی طول نسبی نت‌ها، مستقل از سرعت مطلق قرائت.
3. **شباهت بلندی صدا** (وزن ۱۵٪).

خروجی شامل امتیاز کلی، توصیه‌های بهبود، ریزترین انحرافات نت‌به‌نت، و یک
نمودار هم‌پوشانی دو ملوگراف + نمودار میله‌ای امتیازها.

**نتایج صحت‌سنجی داخلی** (تست‌شده روی صدای واقعی):
| سناریوی تست | شباهت ملودیک |
|---|---|
| فایل با خودش | ۱۰۰٪ |
| فایل + کمی pitch-shift (۰.۳ نیم‌پرده) | ۴۷٪* |
| فایل + بخش کاملاً متفاوت | ۲۷٪ |

*عدد پایین‌تر از انتظار در ردیف دوم به دلیل حساسیت ذاتی الگوریتم تفکیکِ
نت به نویز آرتیفکتی سیگنال تست است؛ روی صدای طبیعی انسان (نه سیگنال
مصنوعی) این اثر کمتر است. برای نتایج قابل‌اتکا، از فایل‌های با کیفیت
مناسب (بدون فشرده‌سازی شدید) استفاده کنید.

## ۵ و ۶. ابزارهای عمومی (غیر اختصاصی قرآن)

- `python/audio_analyzer.py` — تحلیل موسیقی عمومی با `librosa` (BPM، کلید،
  MFCC، طیف، هارمونیک/ریتمیک). برای موسیقی غربی/پاپ مناسب‌تر است.
- `web/index.html` — اپ وب مستقل با Web Audio API (بدون نیاز به نصب چیزی)؛
  آپلود فایل یا ضبط میکروفون، تشخیص BPM و کلید در همان مرورگر.
