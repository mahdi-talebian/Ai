# ردِّ صدا ۱٫۲٫۵ — قاب ۸ نتی ویدیو + نور زرد واضح‌تر + شفاف‌سازی مستندات

## ۱) ویدیو: قاب دقیقاً ۸ نت
پهنای پنجرهٔ نوار متحرک دیگر «۱۵ ثانیهٔ ثابت» نیست؛ از **ریتم خودِ اجرا**
حساب می‌شود: میانهٔ فاصلهٔ «۸ نت پشت‌سرهم» برداشته می‌شود و همان می‌شود پهنای
قاب (با کف ۳٫۵ و سقف ۲۶ ثانیه). نتیجه:

| اجرا | پهنای قاب | نت داخل قاب |
|---|---|---|
| نت‌های ۰٫۵ ثانیه‌ای با فاصلهٔ ۰٫۲۵ | ۶٫۰ ثانیه | ۸ نت |
| نت‌های ۱ ثانیه‌ای با فاصلهٔ ۰٫۴ | ۱۱٫۱ ثانیه | ۸ نت |
| اجرای کمتر از ۸ نت | نمای کامل | همهٔ نت‌ها |

اگر اجرا کوتاه باشد، همان نمای کامل می‌ماند (بدون فضای خالی دو طرف).

## ۲) نور زرد حرکت نت
- **دنبالهٔ درخشان (comet)** پشت نقطهٔ جاری: ۱٫۳ ثانیهٔ اخیر با گرادیان از
  محو به روشن کشیده می‌شود، پس جهت و سرعت حرکت نت دیده می‌شود.
- **ردِ حرکت**: پنج نقطهٔ محو پشت نقطهٔ اصلی.
- خطِ گذشتهٔ اجرا **نازک‌تر و دقیق‌تر** شد (هستهٔ ۲ پیکسل با هالهٔ ملایم) تا
  ویبراتو و پرش‌های کوچک هم دیده شوند؛ هالهٔ نقطه بزرگ‌تر و نقطهٔ سفید مرکزی
  اضافه شد.

## ۳) مستندات: دقت مالِ موتور آفلاین است
در README یک سوءبرداشت روشن بود: بخش بنچمارک با عنوان «نسخهٔ سروری» شروع
می‌شد. اصلاح شد:

- عنوان و توضیح حالا صریح می‌گوید همهٔ کارهای دقت در `web/engine.js` است،
  یعنی **داخل خودِ اپِ آفلاین و APK**؛ نسخهٔ سروری (`python/` + FastAPI) فقط
  حالت اختیاریِ مقایسه است و اپ هیچ‌وقت از آن استفاده نمی‌کند.
- جدول لایه‌ها به‌روز شد: تفکیک نت در آفلاین حالا **Viterbi + شارش طیفی**
  است (نه هیسترزیس).
- دستور تست دقت آفلاین (`node web/tests/accuracy_test.js`) به README اضافه شد.
