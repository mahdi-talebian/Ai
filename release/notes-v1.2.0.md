## ۱) سرعت: ۲ تا ۵ برابر، بسته به تعداد هسته‌های گوشی

تحلیل بین چند Web Worker پخش می‌شود و قطعه‌قطعه (جریانی) اجرا می‌شود؛
حافظه ثابت می‌ماند و درصد پیشرفت همیشه تازه است.

| نسخه | زمان تحلیل ۶۰ ثانیه صدا | نسبت |
|---|---|---|
| ۱٫۱٫۰ | ۴٫۹۵ ثانیه | — |
| ۱٫۲٫۰ (یک رشته) | ۲٫۲۴ ثانیه | **۲٫۲×** |
| ۱٫۲٫۰ (۲ رشته) | ۱٫۸۱ ثانیه | **۲٫۷×** |
| ۱٫۲٫۰ روی گوشی ۴ هسته‌ای | برآورد ~۱٫۰–۱٫۲ ثانیه | **~۴–۵×** |

(اندازه‌گیری روی یک هستهٔ Xeon؛ گوشی هم کندتر است و هم موازی‌سازی بیشتری
بهره می‌گیرد.)

چه چیزی سریع‌تر شد؟

* **FFT حقیقی** به‌جای FFT مختلطِ دوبرابر در استخراج F0، موتور دوم و طیف نت‌ها
* **جدول چرخش کش‌شده** (بدون `Math.cos` در حلقهٔ فریم‌ها)
* **صفر تخصیص آرایه** در حلقهٔ فریم‌ها (بافرهای مشترک)
* **پخش کار بین کارگرها** + برش صدا برای هر کارگر (کل فایل تکثیر نمی‌شود)
* نشان «⚡ N هسته» کنار نوار پیشرفت، تا معلوم باشد کدام مسیر فعال است

> اگر WebView گوشی Worker را نپذیرد، موتور **بی‌صدا** همان مسیر تک‌رشته‌ای را
> اجرا می‌کند. **نتیجه یکسان است** — تست خودکار گزارش دو مسیر را بیت‌به‌بیت
> مقایسه می‌کند.

## ۲) اجرای زنده: دیگر در سکوت نت بالا و پایین نمی‌پرد

هفت لایهٔ محافظ:

| لایه | کار |
|---|---|
| دروازهٔ بلندی | زیر کفِ نویزِ یادگرفته‌شده ⇒ «سکوت» (نت ساخته نمی‌شود) |
| بالاگذر ۷۵ هرتز | هام برق (۵۰/۶۰)، رامبل و لرزش میز حذف می‌شود |
| آستانهٔ دوره‌ای‌بودن | `strength ≥ ۰٫۵۵` و پوشش ≥ ۲٫۵ دورهٔ f0 |
| رد پیک لبه | پیکِ چسبیده به لبهٔ بازهٔ جست‌وجو ⇒ نشانهٔ هام/نویز، نه نت |
| میانهٔ زمانی + رد پرش اکتاو | یک بستهٔ خطا نمایش را جابه‌جا نمی‌کند |
| پایداری ۳ بسته‌ای (≈۰٫۳۶ ث) | نت فقط وقتی نمایش داده می‌شود که مانده باشد |
| مهلت ۰٫۳ ثانیه | بعد از قطع صدا، نت قبلی کوتاه می‌ماند و بعد «—» می‌شود |

**نمایش نرم:** رسم با `requestAnimationFrame` (۳۰ فریم بر ثانیه) و
میان‌یابی نمایی؛ نقطه روی خطوط نت می‌لغزد و نمی‌پرد. متن‌ها فقط با تغییر
واقعی نت عوض می‌شوند (بدون لرزش چیدمان). تحلیل هر بستهٔ ۱۲۰ میلی‌ثانیه‌ای
≈ ۲٫۵ میلی‌ثانیه = ۴۷× سریع‌تر از بیدرنگ، پس خودِ محاسبه لگ نمی‌سازد.

## ۳) آزمون‌های تازه (قابل اجرا با Node)

```bash

                                  #   تُن/ویبراتو/واکل ⇒ نت درست · گذار بدون پرش
node web/tests/parallel_test.js   # ۹ بررسی: تکه‌ها = مسیر کامل · گزارش موازی = سریال
                                  #   خرابی Worker ⇒ بازگشت بی‌صدا
```
