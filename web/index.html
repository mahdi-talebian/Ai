🎧 تحلیلگر هوشمند صوت

ضرب‌آهنگ (BPM)، کلید موسیقی، طیف صدا و بلندی را مستقیم در مرورگر تحلیل کن — بدون نیاز به سرور

🎵 فایل صوتی را اینجا رها کن یا کلیک کن برای انتخاب
پشتیبانی از MP3, WAV, OGG, FLAC, M4A
برای شروع ضبط کلیک کن
شکل موج (Waveform)
طیف فرکانسی زنده هنگام پخش (Spectrum)
کروماگرام میانگین (توزیع انرژی روی ۱۲ نت)
ساخته‌شده با Web Audio API — تمام پردازش‌ها محلی و در همان مرورگر انجام می‌شود
