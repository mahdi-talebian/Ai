## ۲) راه‌حل: مؤلفهٔ مستقل `PitchRangeAnalyzer`

`android-qari/src/ir/hamyareqari/dsp/pitch/PitchRangeAnalyzer.kt` — ورودی `PitchSample`/`FrameIn` (قرارداد مشترک)، یک منطق برای فایل و میکروفن.

### دو محدودهٔ جدا (قابل تفکیک حتی وقتی متفاوت‌اند)

1. **Stable Range — مبنای اصلی گزارش:** بالاترین/پایین‌ترین نتِ دارای **شواهد صوتی + تداوم زمانی** (گروه با ≥۱۰۰ms تداوم از timestamp و میانگین کیفیت ≥۰٫۵۵). نمایندهٔ هر گروه = **میانهٔ فرکانس** اعضا.
2. **Absolute Extrema — لحظه‌ای (تکمیلی):** بالاترین/پایین‌ترین F0 معتبر کل اجرا؛ **نت کوتاه واقعی فقط به‌خاطر کوتاهی حذف نمی‌شود** (پشتوانهٔ ≥۵۰ms یا ≥۲ فریم هم‌سطح)؛ تحریرها/جهش‌های واقعی حفظ می‌شوند.

هر `Extremum` قابل‌ردیابی: `f0Hz` (بدون گرد/کوانتیزه)، `timestampSec`، `noteMidi/noteName` (A4=440، فقط برچسب)، `cents`، `durationSec` (از timestamp)، `qualityScore`، `frameCount`، `stable`. دادهٔ ناموجود = `null` (هرگز مقدار ساختگی — مثلاً نویز خالص: هر چهار مقدار null).

### غربال ناهنجاری (چندجانبه؛ تصمیم تک‌فریمی ممنوع)

- **گروه‌بندی زمانی-فرکانسی** با هیسترزیس (۱۲۰c ادامه / ۳۵۰c اوج تحریر) + وقفهٔ داخل‌گروه ≤۲۵۰ms — vibrato (±۵۰c) و تحریر ملایم یک نت می‌مانند؛ «انحرافِ برگشت‌ناپذیرِ >۲۵۰ms» = تغییر نت واقعی (قاعدهٔ pending).
- **خطای اکتاوِ سگمنتی:** گروه کوتاه (≤۰٫۶s) که فقط پس از ×۲/÷۲ با سطحِ همسایه‌های دوطرفه (±۳۰۰ms) هم‌میزان شود → رد + شمارش (`octaveErrorsExcluded`). جهش اکتاویِ بلند/بدون تطابق اصلاحی = نت واقعی.
- **Median/MAD در فضای لگاریتمی f0** (کف ۲۵c): ناهنجاری سراسری فقط با **تداوم واقعی** (≥۵۰ms) پذیرفته می‌شود — «جهش سریعِ پشتوانه‌دار» می‌ماند (تحریر/جهش واقعی حذف نمی‌شود)؛ تک‌فریمِ بدون پشتوانه رد می‌شود.
- **بلندی صدا وارد تصمیم Pitch نمی‌شود**؛ فریم کم‌حجم ولی تمیز کامل شرکت می‌کند (تست S6/S7).
- همهٔ آستانه‌ها در **`PitchRangeConfig`** در یک محل، با دلیل انتخاب هر مقدار مستند شده‌اند.

### اتصال‌ها (بدون بازطراحی UI؛ LEGACY/ENHANCED حفظ)

| نقطه | تغییر |
|---|---|
| `Analyzer.analyzeSignal` | محدوده از خروجی **گیت+تثبیت‌کننده** (`PitchSampleStream`) — `Report.rangeInfo` افزودنی؛ `highest/lowest`=Stable، `rawHighest/rawLowest`=Absolute (fallback به رفتار قبلی اگر داده نباشد — بدون رگرسیون) |
| `Json.report` | بلوک افزودنی `range_details` (stable/absolute + آمار رد/پذیرش) — کلیدهای قبلی دست‌نخورده |
| UI (`renderReport`) | کارت قهرمان = Stable (مثل قبل)؛ خط «جزئیات محدوده» (Hz/لحظه/سنت/تداوم/کیفیت)؛ بلوک مکمل = لحظه‌ای (متن اصلاح شد: شامل نت کوتاه و تحریر واقعی) |
| زنده (`LiveEngine`) | `PitchRangeAnalyzer.Streaming`: انباشت نمونه‌ها + **بازمحاسبهٔ دوره‌ای از کل داده** (در نخ پس‌زمینه) + **بازبینی نهایی در stop** — مدت‌ها از timestamp واقعی؛ وابسته به تعداد فریم/refresh نیست |
| `build_apk.sh` | پیش‌فرض نسخه با Manifest هماهنگ شد + **نگهبان**: در صورت انحراف نسخهٔ build از Manifest، build قطع می‌شود |
